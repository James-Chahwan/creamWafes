# LayerDAW

Native (Qt) mini-DAW where any track can be generated by AI to fit the rest of the song.
Runs fully local on ACE-Step 1.5 (code + weights MIT licensed).

```
app/      the desktop app (PySide6) — its own venv
engine/   ACE-Step 1.5 checkout + model checkpoints — its own venv (not in git; see Setup)
tools/    setup_engine.sh, test.sh, layerdaw-inspect.py, benchmarks
```

## Setup

Needs Linux, an NVIDIA GPU (tested: GTX 1660 SUPER, 6 GB), [uv](https://docs.astral.sh/uv/), and ~20 GB
of disk. Optional: `rubberband` (pitch without changing speed in the Layer panel).

```bash
tools/setup_engine.sh     # ACE-Step 1.5 at the tested commit + its env + model weights (~10.5 GB download)
cd app && uv sync         # the app itself
```

## Run

```bash
cd ~/Code/musicwork/app
uv run layerdaw                      # new song
uv run layerdaw ~/Music/LayerDAW/song-...   # open a saved one
```

The engine loads in the background (first start compiles kernels and takes a few
minutes); the generate buttons unlock when the status bar says "Engine ready".

## Workflow

- **＋ Add layer** on an empty song makes that part on its own (solo drums, bass, vocals…) at the
  project BPM/key. Or **✦ New idea** (a whole groove from text), or drag audio files in.
- **＋ Add layer** on a song: the engine hears every unmuted track and returns a **new take of the whole
  song with the part added**; the tracks it heard get muted. Every result is a new take — nothing is
  overwritten — so mute/unmute to compare. For **vocals** (ticked by default), drums and bass you can
  **keep only the new part**: it's separated out of the result (Demucs) onto its own track and your
  tracks stay unmuted. Right-click any track → **Keep only ▸ Vocals / Drums / Bass / Everything else**
  splits an existing take the same way (a few seconds).
- **Right-click** the timeline: *Extend to here* (continue a take/the song up to that bar),
  *Redo bars X–Y* (regenerate just the selected section), split, duplicate, rename, export, delete.
- **Drag clips** to move them (snaps to beats; Alt = free). Drag empty lane or ruler = select bars.
- **Ctrl+Z / Ctrl+Shift+Z** undo/redo everything. Songs save automatically.
- **F1** lists every shortcut (Space play/stop, Home, L loop, Esc, Del, Ctrl+D, Ctrl+E, Ctrl+0 fit…).
- Track header: double-click the name to rename, vol/pan sliders (double-click resets), ⟳ new take,
  ⋯ menu. The meter top-right turns red when the mix clips.
- **File → Export stems** writes every track + the mix as 24-bit WAVs from 0:00, ready for Ardour.

## Pads (P)

16 pads in MPC layout (pad 1 bottom-left), played with the mouse, keys **1234 / QWER / ASDF / ZXCV**
(Shift = softer) or any USB MIDI pad controller (notes 36–51, auto-connects when plugged in).
Every pad is the same kind of thing; nothing is tied to a row.

- **Click a pad** to play it and open it in the inspector on the right: name, category, **✦ Generate…**
  (describe a sound, pick the best of 4), **Replace ▾** (the hit at the playhead, selected bars, a clip,
  a file, previous/next hit), and how it plays.
- **Play as Sample / Chord / Note.** *Chord* plays a chord of the song's key with that pad's sound
  (pick which one: i, iv, VI…; flavour triad/7th/sus2/sus4/add9; Strum). *Note* plays one note of the
  key (808s, bass, leads; an 808 sits two octaves down). A sound's pitch is detected so it stays in key;
  with no sound the built-in synth plays. Hold **G** 7th · **H** sus4 · **B** sus2 · **N** add9 while
  hitting chord pads.
- **Ctrl+click** adds/removes pads, **Shift+click** selects a range. With several selected:
  **✦ Make a song from these…**, ✦ Kit / Hooks / Progression onto these, **Chop onto these ▾** (the
  selected clip or a file: kit, at each hit, every beat/half/bar), Play as ▾, Mode ▾, Clear.
- **Drop a WAV on a pad** to load it (a chord pad keeps its chord, with the new sound). Right-click a
  pad for the same actions plus Pitch (±1…12). **File → Chop an audio file onto the pads…** too.
- **● Record pads** plays the song and records your hits and held chords (quantized to 1/16) onto a
  new track. Pads are saved with the song.

## Layer panel (right side)

Click a track's name (or a clip, or its **fx** button) to shape how it sounds. Nothing touches the audio
files: it's applied when the song plays and when you export, and Ctrl+Z undoes it (a slider drag is one
step). **Presets ▾** (Warm & dusty, Lo-fi radio, Big room, Pumping…), **A/B: bypass** to compare, Reset.

- Tone: Warmth (tape/tube saturation), Dark ↔ Bright, Low cut, High cut
- Pitch: ±12 semitones, keeps the speed (Rubber Band)
- Dynamics: Punch (transients + compression), Duck under the kick or any track (sidechain pump)
- Stereo: Width (mono … wide) · Space: Echo (tempo-synced 1/16 … 1/2), Reverb + room size
- **Generate part of this layer:** pick bars (or drag on the ruler, or **Find a gap**), say what goes there
  if you like, ✦ Generate. The AI redoes just those bars of this layer, hearing the rest of it (dry), and
  fills silent bars too. You get a new take with the same sound settings; the old one is muted.

Heavier settings work in the background (a 100 s track: ~1–3 s); the track plays dry until they're ready.

## Make a song from your pads

Select the pads you like (Ctrl+click) → **✦ Make a song from these…** → pick a style (Auto from the
BPM, trap, drill, house, lofi, pop, dnb) and Short (~32 bars) or Full (~72 bars). It arranges exactly
those sounds: no AI, nothing new is generated. Drum pads get patterns with fills (from their category,
name, or the sound itself), chord pads play the progression in order, note/bass pads follow the chord
roots, leads arpeggiate in the choruses, hooks hit in the choruses and break, FX rise into each chorus.
Each pad lands on its own track at the playhead's bar; one Ctrl+Z takes it all back out. In the dialog
each pad also gets **Plays ▾** (which part) and **Notes ▾** (as the pad is set · short · full sample ·
hold to the next hit). Afterwards, right-click a song track → **Song part** to change either, get a new
variation (also ⟳), or re-render it after editing the pad. Sections never go silent: if the pads you
picked don't cover a section's usual parts, it borrows ones you did pick.

Songs from before per-pad chords open with their old chord row as four chord pads and the old hook
row as hook pads.

## Debugging the running app

`~/Music/LayerDAW/session.log` records every action, error and a 5 s health line.
`tools/layerdaw-inspect.py state | screenshot [path] | log [n] | restart` asks the running app directly
(tests use their own socket via `LAYERDAW_SOCKET`, so they never cut it off).
